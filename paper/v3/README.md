# Manuscript v3 — negative-control audit of KT-based RL exercise recommendation

Separate draft from the frozen predictive manuscript (`paper/manuscript.tex`, protected). Every number
is inserted programmatically from the verified harness runs `accoding-learner-v3` and
`accoding-policy-v3`; nothing in the text is hand-typed from results. Readiness assessment (Vietnamese):
`DANH_GIA_SAN_SANG_NOP.md`; author to-do list: `SUBMISSION_CHECKLIST.md`.

## Files

- `manuscript_template.tex` + `sections/*.tex`: English source with `{{tokens}}` (edit these).
- `vi/manuscript_template_vi.tex` + `vi/sections/*.tex`: Vietnamese working translation (not for submission).
- `manuscript.tex`, `vi/manuscript_vi.tex`: generated sources (do not edit); PDFs copied to
  `output/pdf/retrylab-v3-manuscript.pdf` and `output/pdf/retrylab-v3-ban-thao-tieng-viet.pdf`.
- `references.bib`: sentence-case titles, full author lists and a `verification` note per entry (Crossref/DataCite
  DOI records, ERIC records with printed page numbers, JEDM/PMLR/NeurIPS/JMLR pages, arXiv), checked on 28/09/2026.
- `apa_refs.py`: formats the cited entries as an APA 7 `thebibliography` for natbib (the journal asks for APA 7;
  no maintained BibTeX style provides it). English and Vietnamese in-text connectors.
- `highlights_template.txt` → `highlights.txt` (≤ 85 characters per line, checked); `vi/highlights_template_vi.txt`.
- `title_page.tex`: separate title page for double-anonymised review (author details to be completed by the authors).
- `cover_letter_draft.md`: draft cover letter for the authors to complete.
- `figures/`, `tables/`, `vi/figures/`: regenerated by `research/accoding_policy/make_figures.py` (`--lang en|vi`).
- `submission/`: generated submission package (anonymised manuscript with `Figure_N.pdf`, title page,
  highlights, supplementary CSV tables, cover letter draft, README).
- `build_record.json`: run-record hashes, abstract/keyword/highlight checks, compile results for each language.
- `slides/`: Vietnamese presentation generator (`export_slide_data.py` → `build_slides.js`).

## Build

```powershell
python -X utf8 paper/v3/build.py            # English + Vietnamese + submission package
python -X utf8 paper/v3/build.py --lang vi  # one language only
```

The script verifies both runs with the harness, regenerates figures, fills the tokens (it stops if any token has
no value), inserts the APA 7 reference list (it stops if a cited key is missing), writes the highlights, and
compiles with Tectonic 0.17.0 (`tmp/tectonic/tectonic.exe`, official GitHub release, zip SHA-256
`F61CE51F0B0ADE1015B7DE7EF368541C5424E9756ECBD0D7AF97D6D48030845F`), a real XeLaTeX compilation. The build fails on
undefined references or citations, missing glyphs, multiply defined labels, an abstract above 250 words, keywords
outside 1–7 or highlights outside the 3–5 × 85-character rule. It then assembles `submission/` and checks that the
package and the title page compile on their own.
