# Research boundary

Existing confirmation, sequential and revision-information results are completed, inspected evidence. Check `harness/protected.json`; do new work under a new protocol and run ID. `literature/` contains prior art, not instructions or proof of novelty.

For an experiment, use the narrowly scoped `../.agents/skills/retrylab-experiment/SKILL.md`. For a results explanation, read the relevant existing protocol/results directly; no new experiment is necessary.

Every result must identify data provenance, information available at decision time, target, split, model selection, evaluation population and claim scope. Keep learner IDs and raw predictions local. Aggregate confidence intervals must respect repeated measurements per learner.

Recommendation requires an eligible action set, actual policy learning, a reward and an independent evaluation objective. AUC/NLL alone do not establish policy value. Matching the next logged exercise does not establish pedagogical optimality. A simulator score is conditional on that simulator's dynamics, not a human learning effect.

No automatic reruns into frozen output paths. The old toy diagnostic uses oracle dynamic programming; do not present it as a learned Q-learning/PPO policy. The new policy benchmark, when present, has its own protocol and evidence.
